# caivilo.co — Jekyll redesign

This is a redesigned copy of the uploaded Jekyll repository, retaining its project collection, original detailed CV file (`cv/cv.md`), and existing collection pages.

## Deploy
1. Back up the live GitHub repository before changing it.
2. Review all copy, especially legacy files in `_projects/`, `cv/cv.md`, and `collection/` that may contain outdated or sample information.
3. Place your headshot at `assets/images/headshot.jpg`.
4. Upload the contents of this directory to the root of `caivilo/caivilo.github.io` on the published branch.
5. In GitHub Settings → Pages, use GitHub Actions/Jekyll or deploy from branch as configured.
6. Set the custom domain to `caivilo.co` and configure GitHub Pages DNS records at your registrar. Do not remove email DNS records.
7. Enable HTTPS after the domain validates.

No live repository or DNS changes have been made. The original detailed `cv/cv.md` is preserved for reference, not linked from the new navigation because it contains outdated information.
